## Source integration

The native handoff now binds a saved continuation before checking and publication.
After authoritative group drain, completed-request recording uses that captured
request and rechecks the stored request bytes/identity, without requiring the
published output to remain empty. The independent owner also verifies a checking
child's group membership before acknowledging GO. Handoff sets the captured
caller directory and retains the execution-lock descriptor across exec.

The new POSIX TS entry adopts the inherited native control socket, starts a gated
worker through the native group entry, waits for group acknowledgment before GO,
and requests authoritative drain before publication. Its owner channel, signal
handling, complete-report publication and saved-result acknowledgment are scoped
to statechart. The independent native owner drains on public-channel loss before
attempting registered-owned cleanup. An unregistered or uncertain directory is
retained. The owner and anchor use separate groups from the public process and
from each other; the anchor remains unreaped until group drain.

New proof source covers fragmented/wrong/extra/oversize/closed control frames,
terminal acknowledgment, concurrent output preservation and missing/file
destinations. Two native lifecycle cases require an actual pinned Linux binary;
on other systems they assert platform refusal, which is not Linux runtime proof.
No test, Java, javac, TLC, public invocation or container case ran. Linux's statx
directory-identity implementation still explicitly refuses macOS. Bun/Deno
selection and runtime proof, broader abrupt-loss counterexamples, full module
associations and final assurance remain owed. No legacy PS entry is retired.
